# ProfilePush Recruiter Onboarding Playbook

Version: 1.0
Date: 2026-08-01
Audience: New bench sales recruiters and team leads

## 1. Purpose

This playbook defines a practical onboarding path so new recruiters become productive in ProfilePush quickly and consistently.

## 2. Outcomes

By completion, a recruiter should be able to:
- Add and manage candidate profiles in Bench
- Run multi-board searches in Job Finder
- Move high-fit opportunities into Submission Queue
- Use Resume AI and JD AI effectively
- Track outcomes in Tracker
- Understand Job Watch AI scheduling and notifications

## 3. Onboarding Duration and Format

Recommended format:
- Day 0 setup: 45 minutes
- Week 1 guided practice: daily 30-60 minutes
- Week 2 measured production usage

Delivery mode:
- Live walkthrough + task checklist + supervisor review

## 4. Prerequisites

- Active user account
- Team/account assignment
- Access to candidate sample data
- Understanding of basic submission workflow terms

## 5. Day 0 Setup Checklist

1. Sign in and verify account access
2. Confirm profile and notification settings
3. Open each core module once
4. Validate credits visibility and billing awareness
5. Review support and escalation path

Completion signal:
- Recruiter can navigate directly to all core modules without prompts

## 6. Week 1 Learning Path

## 6.1 Module 1: Bench fundamentals

Goals:
- Add profiles via upload and manual edits
- Understand stages and assignments

Hands-on tasks:
1. Upload 3 resumes
2. Validate extracted fields
3. Correct one intentionally wrong field set
4. Assign stage and owner
5. Add one candidate to hotlist

Success criteria:
- 90 percent+ field accuracy after correction
- Candidate records saved without supervisor intervention

## 6.2 Module 2: Job Finder workflow

Goals:
- Execute search across boards
- Interpret match quality

Hands-on tasks:
1. Run search for two different roles
2. Filter and inspect top matches
3. Save 5 jobs to Submission Queue

Success criteria:
- Demonstrates score-informed triage decisions

## 6.3 Module 3: Submission Queue execution

Goals:
- Convert saved jobs into actionable submissions

Hands-on tasks:
1. Open saved queue items
2. Trigger resume rewrite for at least 2 items
3. Mark 3 items as submitted
4. Verify status reflected in Tracker

Success criteria:
- Correctly progresses statuses end-to-end

## 6.4 Module 4: JD AI and Resume AI usage

Goals:
- Use AI tools to improve speed and quality

Hands-on tasks:
1. Paste a JD and run candidate match
2. Export shortlist for one JD
3. Run Resume AI rewrite and compare outputs

Success criteria:
- Can explain why one candidate ranked above another

## 6.5 Module 5: Job Watch AI and Desk

Goals:
- Configure watch schedules and use daily monitoring data

Hands-on tasks:
1. Create one watch schedule
2. Review run outputs or notifications
3. Use Desk metrics to identify one action item

Success criteria:
- Can translate dashboard or watch signal into concrete next task

## 7. Week 2 Performance Ramp

Expected transition:
- Shift from guided tasks to real desk workload

Daily targets (example baseline, adjust per team):
- New/updated profiles: 10-20
- Searches executed: 10+
- Jobs saved: 20+
- Submissions marked: team-specific target

Supervisor checkpoints:
- Data quality
- Stage hygiene
- Submission quality

## 8. Common Mistakes and Corrections

Mistake: Saving incomplete profiles
Correction: Use required-field checklist before final save

Mistake: Ignoring source-level search failures
Correction: Confirm source status and retry failed providers

Mistake: Over-trusting AI score without rationale
Correction: Review score context and candidate fit details

Mistake: Delayed status updates in queue and tracker
Correction: Update immediately after each action

## 9. Operational Standards

## 9.1 Profile quality standard
- Mandatory identity and contact fields
- Location normalized where possible
- Stage and owner always present

## 9.2 Queue hygiene standard
- No stale queue items older than agreed SLA
- Every queue item has next action owner

## 9.3 Tracker integrity standard
- Submission timestamps accurate
- Status transitions auditable

## 10. Escalation Guide

Escalate to team lead when:
- Parse or matching repeatedly fails
- Candidate duplicate conflict cannot be resolved
- Watch automation appears stale

Escalate to platform support when:
- Consistent module errors across users
- Billing/credits mismatch
- Permission or access anomalies

## 12. Certification Framework

Certification levels:
- Level 1: Navigation and data entry
- Level 2: Search and queue execution
- Level 3: Automation and optimization

Assessment format:
- Task-based practical scenarios
- Supervisor evaluation rubric

## 13. Proficiency Metrics

Track per recruiter:
- Time to first completed submission flow
- Profile correction rate
- Queue cycle time
- Submission consistency
- Feature adoption coverage

## 14. 30-60-90 Day Enablement Plan

30 days:
- Stable execution of core workflows

60 days:
- Reliable throughput and low correction rate

90 days:
- Advanced optimization usage and mentoring readiness
